# Neovim keymaps

`<leader>` настроен на `Space`.

## Редактирование

| Сочетание   | Режим    | Действие                               |
|---|---|---|
| `jk`        | Insert   | Перейти в Normal mode                  |
| `<C-Space>` | Terminal | Перейти из Terminal mode в Normal mode |

## Системный буфер обмена

| Сочетание   | Режим           | Действие                             |
|---|---|---|
| `<leader>y` | Normal / Visual | Скопировать в системный буфер        |
| `<leader>Y` | Normal          | Скопировать строку в системный буфер |
| `<leader>x` | Normal / Visual | Вырезать в системный буфер           |
| `<leader>P` | Normal / Visual | Вставить из системного буфера        |

## Копирование путей

Сочетания работают как в обычном файловом буфере, так и на элементе под
курсором в Oil. В Oil можно нажать `V`, выделить несколько строк через `j/k`
и скопировать их тем же сочетанием; пути попадут в clipboard по одному на
строку.

| Сочетание    | Действие                       |
|---|---|
| `<leader>yp` | Скопировать относительный путь |
| `<leader>yP` | Скопировать абсолютный путь    |
| `<leader>yf` | Скопировать только имя файла   |

## Oil — файловая панель

| Сочетание    | Действие                                               |
|---|---|
| `<leader>pv` | Открыть или закрыть Oil слева                          |
| `<CR>`       | Открыть каталог в Oil или файл в соседнем рабочем окне |
| `<C-l>`      | Принудительно обновить содержимое Oil                  |
| `g?`         | Показать встроенную справку Oil                        |

### Операции с файлами в Oil

Oil — редактируемый буфер. Изменения файловой системы применяются только после
сохранения через `<leader>w`; перед применением Oil показывает подтверждение.

| Задача                                                  | Последовательность                               |
|---|---|
| Создать файл                                            | `o`, ввести имя, `jk`, `<leader>w`               |
| Создать каталог                                         | `o`, ввести имя с `/` в конце, `jk`, `<leader>w` |
| Переименовать                                           | `cw`, ввести новое имя, `jk`, `<leader>w`        |
| Удалить                                                 | `dd`, затем `<leader>w`                          |
| Отменить изменение до сохранения                        | `u`                                              |
| Закрыть панель Oil                                      | `<leader>pv`                                     |
| Закрыть текущее окно                                    | `<leader>q`                                      |
| Закрыть открытый файловый буфер без изменения раскладки | `<leader>bd`                                     |

## Нижняя панель

Terminal и LazyGit используют один нижний слот и не создают параллельные
сплиты.

| Сочетание    | Действие                                                      |
|---|---|
| `<leader>tt` | Открыть или закрыть нижний терминал                           |
| `<leader>lg` | Открыть или закрыть LazyGit снизу                             |
| `<leader>tm` | Развернуть активную нижнюю панель или вернуть высоту 15 строк |
| `<C-Space>`  | Перейти из Terminal mode в Normal mode                        |

## Временный редактор промтов

Prompt создаётся только в памяти: без обычного файла и swap-файла.

| Сочетание    | Действие                                               |
|---|---|
| `<leader>ap` | Открыть временный Markdown prompt-buffer               |
| `<leader>ay` | Скопировать весь промт                                 |
| `<leader>aY` | Скопировать промт и уничтожить вкладку                 |
| `<leader>aq` | Уничтожить промт без копирования                       |
| `gT`         | Вернуться из Prompt в предыдущую вкладку               |
| `gt`         | Перейти в следующую вкладку, например обратно в Prompt |

`<leader>ay`, `<leader>aY` и `<leader>aq` доступны внутри Prompt-вкладки.
`gt` и `gT` — стандартные команды Neovim для перехода между вкладками.

## Сохранение и закрытие

| Сочетание    | Действие                                                 |
|---|---|
| `<leader>w`  | Сохранить файл                                           |
| `<leader>q`  | Безопасно закрыть текущее окно                           |
| `<leader>bd` | Закрыть файловый буфер, сохранив раскладку окон          |
| `<leader>Q`  | Выйти из Neovim с подтверждением несохранённых изменений |

`<leader>bd` не удаляет изменённый файл и не применяется к Oil, Terminal или
Prompt.

## Навигация между окнами

Это стандартные сочетания Neovim. Они доступны, потому что `<C-w>` освобождён
в конфигурации Kitty.

| Сочетание | Действие                 |
|---|---|
| `<C-w>h`  | Перейти в окно слева     |
| `<C-w>j`  | Перейти в окно снизу     |
| `<C-w>k`  | Перейти в окно сверху    |
| `<C-w>l`  | Перейти в окно справа    |
| `<C-w>w`  | Перейти в следующее окно |
| `<C-w>=`  | Выровнять размеры окон   |
| `<C-w>q`  | Закрыть текущее окно     |

## Kitty

| Сочетание     | Действие                                       |
| ------------- | ---------------------------------------------- |
| `<C-w>`       | Передать сочетание приложению, например Neovim |
| `<C-S-w>`     | Закрыть текущее окно Kitty                     |
| `<C-A-S-w>`   | Закрыть остальные окна Kitty во вкладке        |
| `<Super-S-p>` | Открыть переключатель Catppuccin               |
